# ATS Information — Getting Started

## American Truck Simulator

BC TRUCK WORKS supports ATS as part of its connected trucking platform.

### Basic flow
1. Install and launch ATS.
2. Configure a supported telemetry provider.
3. Install and configure the BC TRUCK WORKS Windows Connector.
4. Set your BC TRUCK WORKS Driver ID.
5. Start the Connector.
6. Open Driver Hub and verify the connection.
7. Start driving.

### Platform features
Supported features include driver profiles, trips, mileage, fleets, and telemetry.

> Telemetry support depends on the configured provider and connector version.
