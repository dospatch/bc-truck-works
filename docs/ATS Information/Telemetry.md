# ATS Information — Telemetry

## Telemetry workflow

**01 — GAME**  
Start ATS.

**02 — TELEMETRY**  
Start your supported telemetry provider.

**03 — CONNECTOR**  
Start the BC TRUCK WORKS Windows Connector.

**04 — DRIVER HUB**  
Verify that your driver connection is online.

**05 — DRIVE**  
Start trucking and allow supported telemetry to update your data.

### If telemetry does not appear
- Confirm ATS is running.
- Confirm the telemetry provider is running.
- Confirm the Connector is running.
- Verify the Driver ID in the Connector configuration.
- Check Driver Hub.
- If the connection remains offline, use BC TRUCK WORKS Telemetry Help.
