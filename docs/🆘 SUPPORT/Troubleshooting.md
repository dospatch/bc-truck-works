# BC TRUCK WORKS Troubleshooting

## Connector offline
1. Confirm ATS or ETS2 is running.
2. Confirm your telemetry provider is running.
3. Confirm the BC TRUCK WORKS Connector is running.
4. Check the Driver ID.
5. Check Driver Hub again.

## Website problem
Refresh the page and try again. If the problem continues, report the page, action, error message, and approximate time.

## Discord bot problem
Check **📊│bot-status** first. If the bot is online but a command fails, report the command and exact error.

## Still stuck?
Open the appropriate BC TRUCK WORKS support area and provide enough information for the issue to be reproduced.
