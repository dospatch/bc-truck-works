# BC TRUCK WORKS Support Guide

## General Support
For Driver Hub, accounts, community questions, and general assistance.

## Bug Reports
Include the game or feature affected, what happened, steps to reproduce, screenshots or logs when available, and what you expected to happen.

## Telemetry Help
Use this for ATS/ETS2 telemetry, the Windows Connector, mileage, or driver data.

## Technical Help
Use this for the website, Connector, installer, Discord bot, account access, or technical setup.

### Before requesting help
Restart the affected application or Connector, verify your configuration, and include the exact error message when possible.
