# Telemetry Panel

**Title:** 📡 BC TRUCK WORKS TELEMETRY

**Message:**

**01 • GAME** — Start ATS or ETS2.
**02 • TELEMETRY** — Start a supported provider.
**03 • CONNECTOR** — Start the BC TRUCK WORKS Windows Connector.
**04 • DRIVER HUB** — Verify your connection.
**05 • DRIVE** — Start trucking and let supported telemetry update your data.
