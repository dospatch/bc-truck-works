# Bot Status Panel

**Title:** 🚛 BC TRUCK WORKS • BOT STATUS

The status panel reports the current Discord infrastructure state, including:
- 🤖 Bot status
- 📡 Discord connection
- 🌐 Website
- 🛣️ ATS / ETS2 support
- 📡 Telemetry architecture
- ⚙️ Platform version

The live Discord bot owns the status message in **📊│bot-status**.
