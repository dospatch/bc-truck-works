# BC TRUCK WORKS ETS2 Plugin

This folder is reserved for the BC TRUCK WORKS telemetry integration for Euro Truck Simulator 2 (ETS2).

## Purpose

The ETS2 integration will provide game telemetry to the BC TRUCK WORKS Connector.

Planned data includes:

- Speed
- Fuel
- Odometer
- Location
- Game state
- Driving status

## Installation

The Windows installer will prepare the local plugin location.

Target installation area:

C:\BC-TRUCK-WORKS\Plugins\ETS2\

## Status

Telemetry plugin implementation is currently under development.

Do not place unofficial or untested DLL files in this folder.
